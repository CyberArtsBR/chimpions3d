# Golden Forest / Pixel Expedition

Main mode uses warm carved wood, matte moss, jade equipment and golden rewards. Neutral avatar key/fill lighting stays independent of biome color; room reflections preserve metallic materials. Source avatar textures and rest poses are preserved.

Platforms: solid moss-covered timber; moving branches have bound wood and animated outward arrows; fragile branches use split procedural wood even on High, with a central seam and splinters; spring mushrooms have raised spots, gills and subtle elastic motion. Decorations never alter collision bounds or platform trajectories.

Items: tapered banana bunches (two bunches for double rewards), enamel/brass jetpack with gauge, nozzle cavities and two-layer exhaust visible only in flight. Shared geometry/materials limit duplication.

Biomes dissolve over four seconds every 30 seconds of active game time. Night tint and motes blend continuously. Pixel Expedition keeps 3D gameplay and uses fixed, cached pixel dioramas: waterfall forest, overgrown sanctuaries, sunset ridges and bioluminescent grove. No scrolling central trunk in pixel mode. UI accents echo its palette.

Validation: tests and build intentionally not executed, at the user's request. Existing automatic deployment checks are unchanged. Manual review should focus on avatar exposure across dark/white/metallic models, platform recognition, stage transitions and mobile readability.
