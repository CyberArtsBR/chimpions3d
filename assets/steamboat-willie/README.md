# Steamboat Willie guest avatar

This directory stores the compressed, game-ready rig source used by Chimp Jump.
The build reconstructs `public/model/steamboat_willie.glb` and verifies its SHA-256 and 19-bone humanoid hierarchy before packaging.

The supplied source model was credited to **tramdrey** in the original asset metadata. The project owner confirmed permission to use this model in the published game on 2026-09-22.

The Silver Chimp remains available in the character selector; Steamboat Willie is the default player.
